## 6. 环境与工具坑（本机实测）

- 本机**没有任何 Lua 解释器**（`lua`/`lua5.4`/`luajit` 均不在 PATH；`C:\Program Files\Rime\weasel-0.17.4` 只有 weasel.dll/rime.dll/WeaselServer.exe/data；fork 的 `librime` submodule 目录为空）。跑真 Lua 资产用 **wasmoon 1.16.0（已进 devDependencies）**，细节见 `docs/adr/0006-lua-filter-harness.md`。两条硬约束：跨语言桥接函数**禁止返回 null/undefined**（wasmoon 抛 `TypeError: Cannot read properties of null (reading 'then')`，用 `""` 哨兵）；Lua 没有 `{n}` 计数重复量词。
- issue 读写最稳：`gh issue view <n> --json body --jq .body | Out-File -Encoding utf8NoBOM <f>` → 改文件 → `gh issue edit <n> --body-file <f>`。PS5 的 `-Encoding utf8` 会带 BOM 污染首行；`deck_issue_get` 只回 stub，别当正文源。
- PowerShell 里 `--add-assignee "@me"` **必须加引号**（否则 `flag needs an argument: --add-assignee`）。gh 端点偶发 TLS handshake timeout，重试即可。
- `gh issue list` 的 JSON **不含原生依赖边**，要用 `gh api graphql` 的 `blockedBy`。
- 在 `tools.pwsh` 里传 PowerShell 反引号会撑破 JS 模板字面量（报 `Expected ',', got 'ident'`）；改用单引号 JS 字符串 + 分号分隔多条 `Write-Output`。`tools.read` 的 `limit` 上限 20000。
- 仓库 `core.autocrlf` 生效，提交时出现 `LF will be replaced by CRLF` 警告属正常；`assets/lua/*.lua` clone 后换行可能与工作区不同，勿据此比对 sha256。
- 本机 MSBuild：`C:/Program Files (x86)/Microsoft Visual Studio/2019/BuildTools/MSBuild/Current/Bin/MSBuild.exe`；fork 必须经 `weasel.sln`、固定 `Release x64`（`Debug x64` 有 boost C1001 ICE），产物在 `D:/VibeCoding/weasel/x64/Release/`。
