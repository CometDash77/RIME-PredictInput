## 环境备忘（本会话踩过的坑，必读）

- **本 harness（run_code）的子进程环境是裸的：没有 TEMP/TMP/USERNAME/USERPROFILE/USERDOMAIN/COMPUTERNAME**。后果：os.tmpdir() 返回 "undefined\temp"；src/settings/private-directory.ts 的 ensurePrivateDirectory（icacls 私有化目录）抛 "could not establish a private user data directory" → selftest/verify 全挂。解法（已验证）：从 harness 内 spawn pnpm/node/git 时显式注入标准 Windows 变量——SystemRoot=C:\Windows；TEMP=TMP=C:\Users\Administrator\AppData\Local\Temp；USERPROFILE=C:\Users\Administrator；USERNAME=Administrator；USERDOMAIN=COMPUTERNAME=<node os.hostname() 取真机名>；COMPUTERNAME=同值。真实用户/Weasel 宿主环境不受影响；build.mjs 有意未为此打补丁（不用产品代码迁就异常父环境）。
- **gh CLI 未认证**（gh auth login 没跑过）→ issue 操作全走 deck_*（deck github 后端 CometDash77/RIME-PredictInput，自带凭证，实测可用：deck_issue_get/list/create/patch/report，parentKey/assignees/idempotencyKey/progress 段都好用）。
- executor 内嵌 pwsh 不存在 → 用 powershell.exe -NoProfile -ExecutionPolicy Bypass -File。
- git push 偶发 "Recv failure: Connection was reset"（到 GitHub 瞬断）→ 重试即可，本会话第 3 次成功。
