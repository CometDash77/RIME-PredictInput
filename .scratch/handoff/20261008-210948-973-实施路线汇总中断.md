## spec 施工图（照此写，勿再发明）

### A. fork 前端（独立仓库，四项改动）
- 仓库 = `CometDash77/weasel`（**保留 GitHub fork 关系** = 上游合并通道），集成分支 `predict-0.17.4`，自上游 rime/weasel 0.17.4（2025-06-04）**重建**（旧 fork 材料随 reference/ 已丢失，是重建不是恢复）；四项改动各为独立 commit；版本号 `0.17.4-predict.N`。
- 四项改动口径：①TSF 读编辑器正文上文（≤300 Unicode 标量；能确认空上文 vs 读不到要可分）；②IPC 扩展 2 命令 + 私有窗口收完成通知（窗口类 `WeaselIPCWindow_1.0`、COPYDATA_ID `0x52504D31`、载荷 = engine_id/request_id/seq 三段 ID、**不含用户文本**、UTF-8 + 终止 NUL（cbData 计入 NUL）、x64 24 字节 COPYDATASTRUCT；宿主侧找窗一律 EnumWindows + GetClassName 枚举式）；③翻转 option 迫使 librime 重组（无按键刷新）；④右键菜单项唤起本地网页设置页，并保留「禁用与恢复普通菜单」。
- librime 零改动；用户 RIME 数据（方案/custom/词库/userdb）零触碰；**lua 组件、安装器/打包/发布工程归本仓库**；安装器只引用 fork release 产物，不复制 fork 源码树。

### B. 本仓库新增模块（模块内部规则细则）
- **Lua 滤镜组件**：按需拉起伴随进程（锁文件单实例、60s 空闲自退、失败静默留空）、请求组装（engine_id 40 hex / seq 单调 / request_id 32 hex / 设置修订 / 模型身份 / 候选指纹）、按 seq 奇偶读响应槽位、结果映射到**默认第 5 槽位**插入、超时或失败留空、变化即作废旧结果。
- **生成模式**：DecisionInput 扩为 `selection | generation` 双模式判别联合，共用请求身份/缓存/双通道/设置/文件 IPC；Dispatch 签名不变，模式分派收进 inference/service 内部（runtime 无感）；输出必须是**词库内词条**，成员/读音/音节/长度校验失败即安全留空；仍走 Lua 第 5 槽位插入；generation 的 POLICY_DIGEST **独立冻结**（待 #13 出数定稿）；默认开关按 #6 Q6A（不达标则默认关/实验性随包发布）。
- **契约版本**：请求信封与响应记录增补冻结的 contract_version 常量（ADR 0001 增补 + oracle 字节基线更新）；sidecar 与 Lua 双方对未知版本一律安全拒答/留空；**不建运行时协商层**；具体字面值由实施票冻结进 oracle。
- **安装计划路径表**：路径表是注入参数（PayloadTarget，契约层不含字面路径），规则 R1 程序文件根 = 与官方 Weasel 同一处（替换式安装要求同 TSF 身份与同注册位置，具体目录以上游 0.17.4 安装器默认值为准，**实施票核对后冻结**）；R2 自有产物（sidecar 双变体、Lua 组件、设置页资产、安装/卸载引导）集中落在同一功能子目录，禁止散落；R3 用户侧接入点只有两处（RIME 用户目录的 Lua 滤镜接入含 custom 补丁条目、`%USERPROFILE%\.rime-model-predict`），其余用户数据零触碰；R4 安装器构建期把路径表编译进产物。
- **执行器薄壳**：只执行 InstallOp，不决策；幂等重装 = 空增量；中断自愈；共享模型只进 keeps；卸载按 #15 固定序（反注册 TSF → 按 status.json pid + 进程映像校验终止 sidecar（校验不过提示手动退出重试）→ 删自有程序文件与明确接入项 → 删瞬态文件与 diagnostics.log → 还原指引）。
- **安装器形态**：一键安装器 + admin UAC + 替换式安装（与官方 Weasel 同 TSF 身份互斥）+ 还原指引；打包选型（NSIS/Inno/MSI）由实施票定案。
