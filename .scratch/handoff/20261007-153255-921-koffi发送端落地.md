## 环境备忘（本会话新增踩坑，必读）

- **process.execPath 在本 harness 里是 harness 自带运行时**：spawn 它跑脚本会**静默 exit=0 且无输出**（node -e 同样吞掉）。真实 node = `C:\Users\Administrator\AppData\Local\hermes\node\node.exe`（v22.23.1，不在 PATH，用绝对路径）；pnpm.cmd 走 hermes shim 自带可用 node。git/pnpm 直接可用，node 脚本一律真实 node 绝对路径或经 pnpm scripts。
- 环境注入比上一棒多两项：**LOCALAPPDATA=C:\Users\Administrator\AppData\Local、APPDATA=C:\Users\Administrator\AppData\Roaming**——koffi 的 install 脚本（cnoke --prebuild）缺这两项会失败。完整注入集：SystemRoot/TEMP/TMP/USERPROFILE/USERNAME/USERDOMAIN/COMPUTERNAME/LOCALAPPDATA/APPDATA。
- **pnpm add 会往 pnpm-workspace.yaml 的 allowBuilds 自动塞 `<pkg>: set this to true or false` 模板行**；手工放行时删模板行、写 `<pkg>: true`，否则 YAML 重复键解析失败、所有 pnpm 命令报错。
- **koffi FFI 纪律**（已固化在 weasel-messenger-koffi.ts 头注释）：指针尺寸实参必须传 **BigInt**（Number 形态 0xC0000005 崩进程）；koffi.decode 解结构体指针字段恒为 undefined，跨地址抄内存用 kernel32.RtlMoveMemory；结构体回调字段要 `koffi.pointer(proto)` 声明，JS 回调要 `koffi.register(fn, ptr)` 才能活过单次 FFI 调用（裸传 JS 函数是临时闭包）；`koffi.in/out` 在 2.16 已移除（直接 pointer 即可）；按名引用 proto 前必须先 `koffi.proto` 注册；EnumWindows 回调返回 0/1 不是 true/false。
- deck_issue_get 本会话只回摘要行（状态/父票/阻塞计数），**拿全文走 GitHub API 公开端点** `https://api.github.com/repos/CometDash77/RIME-PredictInput/issues/<n>`（公开仓库免认证），改完用 deck_issue_patch body 整体替换（进度段锚：`<!-- 做到哪一步了，在这里一行一行记 -->`）。
