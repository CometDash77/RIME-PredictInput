## 环境陷阱清单（本 session 实测踩过，代价真实）

1. **run_code / execSync 的进程环境被剥空**：`SystemRoot`/`USERNAME`/`TEMP` 等为 null。直接 `pnpm verify` 会挂 18 个产品测试（报 could not establish a private user data directory，icacls 解析不到）。必须补 env 再跑：
   ```js
   const env = { ...process.env, SystemRoot: "C:\\Windows", windir: "C:\\Windows",
     USERNAME: "Administrator", USERDOMAIN: hostname, COMPUTERNAME: hostname,
     TEMP: "C:\\Users\\Administrator\\AppData\\Local\\Temp", TMP: 同上 };
   execSync("pnpm run verify", { env, shell: "cmd.exe" });
   ```
2. **pwsh 工具就是 PowerShell**：不能嵌套调 `pwsh` 命令（CommandNotFoundException）；跑 .ps1 脚本要 `Set-ExecutionPolicy -Scope Process Bypass -Force; & '脚本路径'`（脚本执行策略默认禁运行）。
3. **网络**：raw.githubusercontent.com 本机可直连；api.github.com 间歇抖动（重试）；jsdelivr/gitee/ghproxy 不可靠或 404（rime-frost 词库在 master 分支，用 main 会 404）。大文件下载用 `eval/.cache/fetch-dicts.ps1`（镜像回退 + 尺寸校验 + 断点续传），后台跑 `pwsh(..., run_in_background:true)`。
4. **生成代码文件的转义陷阱**：通过 run_code 调 tools.write 写文件时，程序字符串里的 \n 落盘为真实换行。想在生成文件里得到字面量 "\n"（如 `lines.join("\n")`），必须写 \\n。写完大文件先 typecheck 再信任。
5. **冻结资产勿手改**：samples.jsonl/manifest.json 已加 `.gitattributes -text` 防换行漂移；`pnpm eval:check` 校验逐行哈希，手改即拒绝。改样本/口径必须 `pnpm eval:build` 重建；改 `src/eval/syllables.ts` 音节表 = 改口径，必须重建留出集并重冻结。
