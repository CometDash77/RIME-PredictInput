## 刚定位到的根因（本轮核心产出，还没改码）

1. **pe.mjs CLI 解析 bug（已实锤）**：node 下 process.argv = [nodeExe, 脚本路径, "copy-gui", src, dst]，而 pe.mjs:43 写的 `const [, cmd, ...rest] = process.argv` 只跳过 argv[0]，cmd 实际=脚本路径 → 永远走 else 打 usage、exit 0、不干活。debug-cmd.mjs 实测输出：CMD="D:\...\debug-cmd.mjs" REST=["copy-gui",...]。这就是 run.ps1 GUI 步 usage×5、5 个 -gui 产物全缺的根因。修法：`const [, , cmd, ...rest] = process.argv;`。guard 本身（import.meta.url===pathToFileURL(argv[1]).href）已实测正确，别动。
2. **run.ps1:44 Build-Sea output 字段 bug**：`$cfg.output = "build\" + (Split-Path $configJs -Leaf)` 把 blob 输出写成 config 同名路径 → node 把二进制 blob 覆盖写到 build\sea-probe-config.json（4909 字节的它就是 blob），随后 Test-Path .blob 失败 → sea-real/sea-probe FAIL。修：`$cfg.output = "build\" + ((Split-Path $configJs -Leaf) -replace '\.json$','.blob')`（line 47 的 $blob 已经是对的）。
3. **esbuild sea-bundle 失败（2 errors 实锤）**：dist/cli/main.js:133-136 有顶层 await guard（`const invokedDirectly = process.argv[1] !== undefined && import.meta.url === pathToFileURL(process.argv[1]).href; if (invokedDirectly) { process.exitCode = await main(process.argv.slice(2)); }`），CJS 输出不支持 TLA；且 CJS bundle 里 import.meta 为空 → pathToFileURL(undefined) 会在运行时崩。修法（新建 strip-guard.mjs）：把 dist/cli/main.js 读入，用正则 /\r?\nconst invokedDirectly[\s\S]*?process\.exitCode = await main\(process\.argv\.slice\(2\)\);\r?\n\}\r?\n?/ 剥掉该块写 build/main-noguard.mjs；**正则不命中必须 exit 1**（防静默坏 bundle）。esbuild 加 --alias:../../dist/cli/main.js=./build/main-noguard.mjs。
4. **deno-entry 编译失败**：deno-entry.mjs 传递 import zod，deno 无法用 pnpm 的 node_modules（报 @types/node/nodeModulesDir 错误，probe-deno.mjs 因无 npm imports 编译成功）。修法：esbuild 把 deno-entry.mjs 打成单文件 ESM（--platform=node --format=esm --alias 同上 --outfile=build/deno-bundle.mjs，node: 内置 deno 原生支持），run.ps1:86 改编译 build/deno-bundle.mjs。deno-builds 步要加 Test-Path 检查（之前失败却标 OK）。
5. **helper.cs:174 recv ready 行缺 \n**：ready JSON 与第一条 WM_COPYDATA 记录连成一行 → JSONL 首行 parse 失败被过滤 → P7 node-baseline received:null（它的条目 cbData22 utf8 "node-baseline\nreq-1\n1\0" 完好躺在 %TEMP%\proto-recv.jsonl 第一行）。修：ready 行尾加 "\n"；run-measurements 的 entries 解析可同时改 /{[^{}]*}/g 全局匹配做双保险。
6. **probe-deno.mjs FindWindowW 编码 bug**：line 15-17 用 TextEncoder（UTF-8）喂 FindWindowW(['pointer','pointer']) → found:false。修：手工构造 UTF-16LE：`const wide=(s)=>{const b=new Uint8Array((s.length+1)*2);for(let i=0;i<s.length;i++){const c=s.charCodeAt(i);b[i*2]=c&0xff;b[i*2+1]=c>>8;}return b;};` 用 Deno.UnsafePointer.of(wide("WeaselIPCWindow_1.0"))。payload 保持 UTF-8（receiver 按 utf8 字段匹配）。
7. **run-measurements P1 读 stdout bug**：helper consoles 结果写文件不写 stdout，`parseFirstJson(run(HELPER,["consoles",...]).stdout)||{count:-1}` 全变 -1。改读 fs.readFileSync(PROTO+"\\_c0.json")（baseline）和 _c2.json（during）。_c1 已是文件读，别动。
