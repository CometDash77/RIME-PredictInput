## 6. 环境与工具坑（本机实测）

- 本机**没有任何 Lua 解释器**（`lua`/`lua5.4`/`luajit` 都不在 PATH）。Lua 资产一律用 **wasmoon 1.16.0**（已在 devDependencies）跑，见 `docs/adr/0006-lua-filter-harness.md`、支架 `tests/support/lua.ts`。硬约束：跨语言桥接函数**禁止返回 null/undefined**（用 `""` 哨兵）；Lua 没有 `{n}` 计数重复量词。
- issue 读写最稳：`gh issue view <n> --json body --jq .body | Out-File -Encoding utf8NoBOM <f>` → 改文件 → `gh issue edit <n> --body-file <f>` → **再取一次正文做逐字节比对**，确认只有目标行变了。PS5 的 `-Encoding utf8` 带 BOM（读回需 `replace(/^\uFEFF/,'')`）；`deck_issue_get` 只回 stub，别当正文源。
- `gh issue view <n> --jq '<复杂表达式>'` 在 pwsh 里会静默失败（exit 1、stdout 空）——踩过。用 `--json body` + 落盘再读。
- **`git add` 只要有一条 pathspec 不存在，整条命令 fatal 中止**（其余路径不 staged），随后的 `git commit` 可能只提交先前已 staged 的部分（`5f7dcac` 就是这么产生的）。列路径前先确认文件存在。
- PowerShell 里 `--add-assignee "@me"` **必须加引号**；gh 偶发 TLS handshake timeout，重试即可。
- 在 `tools.pwsh` 里传 PowerShell 反引号会撑破 JS 模板字面量；改用单引号 JS 字符串 + 分号分隔多条 `Write-Output`。`tools.read` 的 `limit` 上限 20000。tsconfig **不覆盖 `.scratch/`**，探针测试放 `tests/` 下并记得删。
- 仓库 `core.autocrlf` 生效：提交时 `LF will be replaced by CRLF` 警告正常；`assets/lua/*.lua` clone 后换行可能与工作区不同，别据此比对 sha256。
- vitest 被中断会在 `tests/` 留下 `.<testfile>.tmpdir/` 残留，收口前清掉。
- 本机 MSBuild：`C:/Program Files (x86)/Microsoft Visual Studio/2019/BuildTools/MSBuild/Current/Bin/MSBuild.exe`；fork 必须走 `weasel.sln`、固定 `Release x64`（`Debug x64` 有 boost C1001 ICE），产物在 `D:/VibeCoding/weasel/x64/Release/`。
- 长命令可放后台（`run_in_background`），但**给结论前必须读回结果**。
