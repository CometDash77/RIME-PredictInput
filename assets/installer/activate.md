# 接入模型预测

安装器保持已有方案、custom、词库、userdb 和共享模型原样。
安装 Lua 组件不会自动启用滤镜。请先备份要启用的方案的 custom 文件，再手动合并以下条目，
不要覆盖已有 patch 或重复追加：

```yaml
patch:
  "engine/filters/@next": lua_filter@*model_predict_filter
```

修改后由用户执行一次小狼毫重新部署。卸载前请手动移除此条自有接入项，保留其他补丁。
如果不愿修改方案，保持普通输入即可。不要开启尚未通过质量门槛的实验性生成模式来替代普通输入。

首次安装前请先安装官方 Weasel 0.17.4，保留它的共享 data 目录；本包执行前端替换，
不分发或管理词库，也不创建第二套输入法身份。退出小狼毫服务与所有使用其前端的编辑器后安装。
如果文件仍被占用，请保存工作、注销后重新登录，再重试安装；失败步骤会保留在安装记录中。
安装结束后由用户启动 WeaselServer.exe；托盘的模型预测设置入口打开本地设置页。
