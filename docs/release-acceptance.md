# 真机发布验收清单（Windows 11 x64）

依据 #16 三轮 grilling 结论（2026-10-08，YG 逐项确认）。场景范围 = #18 spec「归真机」全集 ∪ #9 遗留四项 ∪ fork 四项前端改动端到端 ∪ #16 原四场景。

- 适用产物：fork release（CometDash77/weasel，`predict-0.17.4.N`）+ 本仓库安装器（内嵌 sidecar 双变体、Lua 组件、设置页资产）。
- 执行者：YG，真实环境手动执行；禁 UI 自动化（#18 Out of Scope）。
- 环境：Windows 11 x64 物理机（唯一真机）。首发支持矩阵已降级为 Win11 实测通过（#16 决策 7，#18 进度区 2026-10-08 修订行）。
- 修订纪律：本文件判据变更走普通 PR 并在 #16 结论区记一行；每轮执行结果不进仓库。

## 执行协议

1. 一轮 = G0→G6 顺序连续执行，中途不改环境配置。
2. 判据分级：**硬 gate**（S-01…S-07、S-09…S-13）任一失败 ⇒ 本轮失败，不发布；**记录性**（S-08、S-14）只记录不阻塞。
3. 失败处置：任何场景失败 ⇒ 停轮，记录证据与归属（fork / sidecar / 安装器 / 环境），修复后**全量重跑新一轮**（含已通过场景）。
4. 延迟判定全部为体感（YG 主观裁量）：#6 Q9 数值门槛（热态 median ≤400 ms / p90 ≤900 ms / max ≤1500 ms 等）由 #12/#13 冻结留出集上的 rig 复跑兑现，真机轮不采集计时样本。
5. 记录：每轮结果写入当轮验收 issue 评论（模板见文末）；仓库不留执行结果。
6. fork 施工冒烟：S2/S3/S4 每张施工票完成后，立即在真机执行对应场景的「施工冒烟」步骤（10 分钟级），不等到发布验收。

## G0 生命线

### S-01 安装器真机安装 — 硬 gate

- 前置：Win11 物理机已装官方 Weasel 0.17.4（验证替换式安装）；安装器为 Release 候选产物。
- 步骤：
  1. 运行安装器 → UAC 提示出现，授权后安装完成。
  2. 核对程序文件落位（R1 与官方 Weasel 同根、R2 功能子目录、R3 用户接入点）与安装器内嵌产物 sha256 一致。
  3. 核对 ProgramData 部署位置 ACL：普通用户进程可读可运行，无越权写入用户目录（#9 遗留项在此实测）。
  4. 确认 RIME 用户目录接入项（Lua 滤镜、custom 补丁条目）就位；方案/词库/userdb 未被触碰。
- 判据：落位与路径表一致；ACL 不阻塞安装与运行；用户数据零触碰；UAC 正常。
- 施工冒烟：无（与 fork 无关）。

### S-02 普通输入不降级冒烟 — 硬 gate

- 前置：S-01 完成；Ollama 未运行（或 `local_base_url` 指向不可达端口），模拟故障态。
- 步骤：
  1. 记事本连续输入拼音：候选窗正常出现，第 1–4 位普通候选，第 5 位留空，无可感知阻塞。
  2. 任务管理器观察 sidecar 在首次输入后按需拉起。
  3. 停止输入约 60 秒，观察 sidecar 自动退出。
- 判据：故障态只留空不阻塞（CONTEXT 领域规则 1）；sidecar 按需启动、60 秒空闲自退。
- 施工冒烟：无。

## G1 上文与刷新（fork 改动 1/2/3 端到端）

### S-03 真实编辑器上文读取 — 硬 gate

- 前置：完整链路在场（Ollama 运行、模型可用）。
- 步骤：
  1. 编辑器中输入多行文本，光标置于段中再输入拼音：请求携带真实上文（`diagnostics.log` metadata 模式有请求事件，无正文）。
  2. 新建空文档直接输入拼音：可确认的空上文（`precedingText === ""`），仍可预测。
  3. 浏览器登录表单密码框聚焦时输入：protected，不发请求。
  4. 构造 >300 标量长上文：截断不崩溃。
- 判据：ContextSnapshot 三态行为正确——ok（含可确认空上文）/ unavailable / protected；空上文 ≠ 读不到，读不到不发请求。
- 施工冒烟（S2 施工票完成后）：步骤 1–3 精简复跑。

### S-04 完成通知真机刷新链路 — 硬 gate

- 前置：完整链路在场；fork 为含 IPC 扩展与 option 重组的 release。
- 步骤：
  1. 输入拼音停手：普通候选立即出现。
  2. 模型结果到达时候选窗**无需额外按键**即刷新，第 5 位出现模型候选。
  3. 连续多轮观察：无重复候选、无闪烁、普通候选顺序无扰动。
- 判据：WM_COPYDATA 完成通知（窗口类 `WeaselIPCWindow_1.0`、COPYDATA `0x52504D31`）→ option 翻转 → librime 重组 → 立即刷新；全程无普通候选扰动（#9 P7 遗留在此实测收口）。
- 施工冒烟（S3 施工票完成后）：步骤 1–2 复跑。

## G2 选择与提交

### S-05 第 5 位提交 — 硬 gate

- 步骤：
  1. 输入有模型候选的拼音，按 `5` 选中第 5 位。
  2. 上屏内容与模型候选逐字一致。
- 判据：上屏正确；**体感判据：停手后第 5 位可选项出现无可感知迟滞**（数值门槛归 #12/#13 rig）。
- 施工冒烟：无。

### S-06 上下文突变作废 — 硬 gate

- 步骤：
  1. 输入拼音触发预测，结果到达前粘贴大段文本：结果到达后不显示（身份作废）。
  2. 第 5 位候选已显示未提交时，光标上移或删除字符改变上文：旧候选不再可选，不误提交。
  3. 切换文档/应用：旧结果零残留。
- 判据：任何上下文突变后旧结果零显示、零提交（CONTEXT 领域规则 3）。

### S-07 第 1–4 位回归 — 硬 gate

- 步骤：与无插件基线对照，多组拼音观察第 1–4 位候选顺序。
- 判据：普通候选顺序与基线一致；原本正确的首选零改错（#6 Q8 候选内回归断言）。

## G3 生成（组内顺序：先机械后体验，S-09 → S-08）

### S-09 生成安全留空 — 硬 gate

- 前置：生成开关默认关闭态先验证。
- 步骤：
  1. 生成关闭：任何输入无生成候选，普通输入正常。
  2. 生成开启（设置页实验性开关）：构造成员/读音/音节/长度校验必败场景：第 5 位留空，无错误提示。
- 判据：校验失败即安全留空；开关关闭时生成完全不参与。

### S-08 生成词条插入与人工复核 — 记录性

- 前置：生成开启；词库含可命中词条。
- 步骤：
  1. 输入生成场景拼音：第 5 位出现词库内词条。
  2. 提交后在真实编辑器里通读生成词句，人工复核与上文的贴合度。
- 判据（记录性）：词条全部在词库内、零造词；复核印象写入轮次记录。数值质量判定归 #13 冻结留出集，本场景不 gate（#6 Q7 窗口结论单列）。

## G4 外围

### S-10 右键菜单设置入口 — 硬 gate

- 步骤：
  1. 托盘/输入法右键菜单出现设置入口，点击后浏览器打开 `http://127.0.0.1:48371/#<token>`。
  2. 设置页可读改设置，保存后生效（`settings.json` 更新）。
  3. 禁用插件与恢复普通菜单路径可用。
- 判据：会话只绑回环（Host/Origin 校验）；禁用/恢复路径正常（fork 改动 4 端到端）。
- 施工冒烟（S4 施工票完成后）：步骤 1–2 复跑。

### S-11 云端 opt-in 与更新检查真实行为 — 硬 gate

- 前置：准备真实云端凭据（YG 自有）；抓包或防火墙日志侧证出站。
- 步骤：
  1. 云端关闭态（默认）：任何输入零出站（侧证）。
  2. 开启云端：设置页明示披露（正文、拼音、候选发往所配服务商）→ 配置凭据 → 真实出站一次推理成功。
  3. 更新检查：打开设置页触发匿名 GET（固定 URL、静态 UA、无 body）；断网或关闭开关：完全静默。
- 判据：关闭态零出站；开启态出站与披露一致；更新检查 stable-only、失败静默、绝不自动下载。

## G5 生命周期

### S-12 一次服务重启 — 硬 gate

- 步骤：
  1. 输入拼音在途时重启 Weasel（托盘退出重开）。
  2. 恢复后输入：链路自愈，候选正常，无错位响应。
  3. 检查 `ipc/requests/`、`ipc/responses/<engine_id>/` 残留被消费或清理；任务管理器确认 sidecar 单实例。
- 判据：重启后自愈；单实例锁有效；瞬态文件无脏残留（#16 场景 4）。

### S-13 卸载与重装 — 硬 gate

- 步骤：
  1. 卸载：固定序执行（反注册 TSF → pid+进程映像校验终止 sidecar → 删程序文件与接入项 → 删瞬态与 `diagnostics.log` → 还原指引展示）。
  2. 卸载后普通输入仍可用（官方 Weasel 形态），无自有残留进程。
  3. 核对 `settings.json` 保留、共享模型保留。
  4. 重装：设置自动恢复，无需重新配置。
- 判据：卸载幂等、普通输入恢复、重装恢复设置、共享模型零重下。
